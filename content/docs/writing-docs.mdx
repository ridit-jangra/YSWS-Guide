---
title: Writing docs
description: How to add pages to this site
---

Create a file in `content/docs`, add a title in the frontmatter, and you're done.

```md
---
title: My page
description: What it's about
---

# Hello
```

Sidebar order comes from a `meta.json` in the same folder:

```json
{ "pages": ["index", "getting-started", "writing-docs"] }
```
